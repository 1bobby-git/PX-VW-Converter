# PX ↔ VW Converter

기준 뷰포트 너비를 바탕으로 **PX와 VW를 즉시 계산**하고, CSS 소스 안의 단위를 **PX ↔ VW 양방향으로 일괄 변환**하는 브라우저 도구입니다.

- 서비스: https://1bobby-git.github.io/PX-VW-Converter/
- 외부 라이브러리와 서버 통신 없이 정적 파일만으로 동작합니다.

## 주요 기능

### 단일 값 변환

- PX → VW, VW → PX 실시간 계산
- 360 / 375 / 390 / 414 / 768 / 1440 / 1920 뷰포트 프리셋
- 최대 소수점 0~6자리 설정 및 불필요한 뒤쪽 0 제거
- 계산 결과 원클릭 복사
- 브라우저별 설정 자동 저장

### CSS 소스 변환

- PX → VW와 VW → PX 양방향 변환
- 변환 대상 단위가 포함된 선언만 유지하는 필터
- 필터링 후 비어 있는 CSS 규칙 자동 제거
- `0px`, `0vw`를 `0`으로 정리하는 선택 옵션
- 입력을 멈추면 자동 변환하거나 버튼으로 수동 변환
- CSS 파일 열기, 드래그 앤 드롭, 결과 파일 저장
- 변환 개수, 제거한 선언 개수, 결과 파일 크기 표시
- 주석, 따옴표 문자열, `url(...)` 내부 값은 변환 대상에서 제외
- `@media`, `@supports`, `@container`, `@keyframes`, CSS 중첩 규칙 처리

## 사용 예시

기준 뷰포트가 `375px`일 때:

```css
.card {
  width: 320px;
  padding: 24px 16px;
  color: #334155;
}
```

`PX → VW` 변환 결과:

```css
.card {
  width: 85.33vw;
  padding: 6.4vw 4.27vw;
}
```

`대상 단위가 포함된 선언만 유지` 옵션이 켜져 있으므로 `px` 값이 없는 `color` 선언은 제거됩니다.

## 단축키

- CSS 입력 영역에서 `Ctrl + Enter` 또는 `Command + Enter`: 즉시 변환
- CSS 입력 영역에서 `Tab`: 공백 2칸 입력

## 구성

```text
.
├── index.html          # 시맨틱 마크업과 화면 구조
├── styles-1.css        # 공통 디자인 토큰과 기본 레이아웃
├── styles-2.css        # 변환 카드와 CSS 작업공간
├── styles-3.css        # 에디터, 반응형, 다크 모드, 접근성
├── converter-core.js   # CSS 탐색·필터·단위 변환 엔진
├── app-ui.js           # 화면 상태, 저장, 복사, 파일 처리
└── .nojekyll           # GitHub Pages 정적 배포 설정
```

## 기술적 특징

- 외부 폰트, 프레임워크, 분석 스크립트 없음
- HTML에서 정적 CSS·JavaScript 자산을 직접 병렬 요청
- 모바일 320px부터 데스크톱까지 반응형 대응
- 라이트·다크 모드 및 사용자 설정 저장
- 키보드 포커스, 스크린리더 상태 안내, 모션 감소 설정 지원
- 입력한 CSS는 브라우저 밖으로 전송하지 않음
- 변환 엔진과 UI 로직을 분리해 기능 테스트와 유지보수가 쉬운 구조
