# PX ↔ VW Converter

기준 뷰포트 너비를 바탕으로 **PX와 VW를 실시간 계산**하고, CSS 소스의 단위를 **PX ↔ VW 양방향으로 일괄 변환**하면서 문법 오류와 오타 가능성을 함께 확인하는 브라우저 도구입니다.

- 서비스: https://1bobby-git.github.io/PX-VW-Converter/
- 외부 라이브러리나 서버 통신 없이 정적 파일만으로 동작합니다.
- 입력한 CSS는 브라우저 밖으로 전송하지 않습니다.

## 주요 기능

### 단일 값 변환

- PX → VW, VW → PX 입력 즉시 계산
- `320 / 360 / 800 / 801 / 1100 / 1440 / 1920` 뷰포트 프리셋
- 최대 소수점 0~6자리 설정 및 불필요한 뒤쪽 0 제거
- 양쪽 변환 카드와 숫자 입력 컨트롤 높이 통일
- 결과 원클릭 복사 및 브라우저별 설정 저장

### CSS 소스 변환

- PX → VW와 VW → PX 양방향 변환
- 입력할 때마다 다음 화면 프레임에서 결과 즉시 갱신
- 필터 사용 시에도 기존 줄바꿈·공백·탭·중괄호 배치를 가능한 그대로 유지
- 변환 대상 단위가 포함된 선언만 유지하는 선택 필터
- 필터링 후 비어 있는 CSS 규칙 자동 제거
- `0px`, `0vw`를 `0`으로 정리하는 선택 옵션
- CSS 파일 열기, 드래그 앤 드롭, 결과 파일 저장
- 변환 개수, 제거한 선언 개수, 결과 파일 크기 표시
- 주석, 따옴표 문자열, `url(...)` 내부 값은 변환 대상에서 제외
- `@media`, `@supports`, `@container`, `@keyframes`, CSS 중첩 규칙 처리

### CSS 문법·오타 검사

입력과 동시에 다음 항목을 검사하고 오류 위치를 `행:열` 형식으로 표시합니다. 검사 항목을 누르면 해당 위치가 선택됩니다.

- 닫히지 않은 중괄호, 대괄호, 괄호, 문자열, 주석
- 속성명과 값 사이의 콜론 누락
- 선언 사이의 세미콜론 누락 가능성
- 비어 있는 속성명 또는 속성값
- 잘못된 `!important` 철자
- 알 수 없는 `@` 규칙
- 브라우저가 인식하지 못하는 CSS 속성명과 속성값
- `widht → width`, `gird → grid` 같은 인접 문자 순서 오타 제안
- `calas`, `calss`, `claas` 등 `class` HTML 속성 철자 오타 경고 (`.calas` 같은 임의 클래스명은 제외)

브라우저 기반 정적 검사이므로 프로젝트 전용 전처리 문법이나 향후 CSS 문법은 경고로 표시될 수 있습니다.

## 사용 예시

기준 뷰포트가 `320px`일 때:

```css
.card {
  width: 160px;
  padding: 24px 16px;
  color: #334155;
}
```

`PX → VW` 변환 결과:

```css
.card {
  width: 50vw;
  padding: 7.5vw 5vw;
}
```

`대상 단위가 포함된 선언만 유지` 옵션이 켜져 있으면 `px` 값이 없는 `color` 선언은 제거됩니다.

## 단축키

- CSS 입력 영역에서 `Ctrl + Enter` 또는 `Command + Enter`: 즉시 재검사·재변환
- CSS 입력 영역에서 `Tab`: 공백 2칸 입력

## 자동 테스트

Node.js 22 이상에서 별도 패키지 설치 없이 전체 테스트를 실행할 수 있습니다.

```bash
node --test tests/*.test.js
```

테스트 범위에는 단위 변환, 안전한 CSS 탐색, 중첩 규칙, 원본 포맷 보존, 문법 오류 소스 처리, 문법 검사, 요청한 뷰포트 목록, 화이트 전용 UI, 실시간 처리, 동일 높이 레이아웃과 정적 자산 연결 검사가 포함됩니다. `main` 브랜치 푸시와 Pull Request마다 GitHub Actions가 JavaScript 문법 검사와 회귀 테스트를 자동 실행합니다.

## 구성

```text
.
├── .github/workflows/test.yml  # JavaScript 문법 및 회귀 테스트 자동화
├── tests/
│   ├── class-attribute-typo.test.js # class 속성 오타 검사
│   ├── converter-core.test.js       # 변환·문법 검사 엔진 테스트
│   ├── format-preservation.test.js  # 원본 포맷 보존 회귀 테스트
│   └── ui-contract.test.js          # UI 요구사항과 정적 자산 검사
├── index.html                  # 시맨틱 마크업과 화면 구조
├── styles-1.css                # 화이트 디자인 토큰과 기본 레이아웃
├── styles-2.css                # 변환 카드와 CSS 작업공간
├── styles-3.css                # 검증 결과, 반응형, 접근성
├── converter-core.js           # CSS 탐색·필터·변환·기본 문법 검사 엔진
├── app-ui.js                   # 실시간 UI, 오타 제안, 저장, 복사, 파일 처리
└── .nojekyll                   # GitHub Pages 정적 배포 설정
```

## 기술적 특징

- 화이트 모드만 제공해 운영체제 테마와 무관하게 동일한 화면 유지
- 외부 폰트, 프레임워크, 분석 스크립트 없음
- `requestAnimationFrame`으로 입력 이벤트를 한 화면 프레임 단위로 병합
- CSS를 새로 포맷하지 않고 원문 구간을 유지한 채 불필요한 선언만 제거
- 모바일 320px부터 데스크톱까지 반응형 대응
- 800px 이하 1열, 801px 이상 2열 단일 변환 레이아웃
- 키보드 포커스, 스크린리더 상태 안내, 모션 감소 설정 지원
- 변환 엔진과 UI 로직을 분리해 유지보수와 자동 검증이 쉬운 구조
